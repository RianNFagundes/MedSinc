# MedSinc

TCC em equipe do curso de Ciência da Computação da UNIP. O MedSinc é um sistema web para acompanhar a agenda de plantões médicos, candidatar-se a vagas de plantão e registrar gastos e atendimentos.

## Código e instalação

| Componente | Tecnologias | Código da equipe |
| --- | --- | --- |
| Interface web | React, TypeScript, Vite, Tailwind CSS e Recharts | [Frontend](https://github.com/HierroPagotto/plantaoMedicoFinance) |
| API e banco de dados | Python, Flask, SQLAlchemy, Alembic e MySQL | [Backend](https://github.com/HierroPagotto/MedSincBackend) |

Para rodar localmente, configure o MySQL 8 e siga o [guia do backend](https://github.com/HierroPagotto/MedSincBackend#configuração) com Python 3.10 ou superior. Com a API no ar, siga o [guia do frontend](https://github.com/HierroPagotto/plantaoMedicoFinance#configuração) com Node.js 20 ou superior.
